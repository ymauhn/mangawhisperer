# Modelos com licença não-comercial são aceitáveis (projeto pessoal/filantrópico)

O MangaWhisperer é um protótipo pessoal e de portfólio que, no máximo, vira um
projeto open-source com fim filantrópico (pesquisa em inclusão). **Uso comercial
está fora do horizonte**, então licenças de modelo que proíbem comércio — como a
CPML do XTTS v2 — não são impedimento para o TTS ou o VLM padrão. A escolha de
modelos é decidida só por qualidade, VRAM e reprodutibilidade.

## Consequences

- Um futuro leitor não deve "corrigir" o XTTS por causa da CPML: foi deliberado.
- Se o horizonte mudar (uso institucional pago, distribuição comercial), este ADR
  é substituído e o TTS/VLM padrão precisa ser reavaliado entre opções
  license-clean (MIT/Apache) — a factory de motores já permite a troca.
- A licença do próprio repositório continua indefinida até a abertura para
  contribuições (registrado como fog no mapa).
